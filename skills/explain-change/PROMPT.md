# explain-change: instructions for agents without skill support

Reference this file from `AGENTS.md` (or paste it into your agent): "To explain a code change visually, follow
~/.agents/skills/explain-change/PROMPT.md".

---

To explain a code change (a branch, uncommitted work, or an Azure DevOps or GitHub PR) visually, read
`~/.agents/skills/explain-change/SKILL.md` and follow it from its first heading. Where it names the
`explain-change-configure` skill, follow `~/.agents/skills/explain-change-configure/SKILL.md`.
